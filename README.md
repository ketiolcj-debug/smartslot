# SmartSlot 5 — GitHub Pages frontend

This is the redesigned GitHub Pages frontend based on the supplied Multi Hot 5 source: 3 reels, 5 fixed paylines, multipliers and the source paytable values.

Upload `index.html`, `style.css`, and `app.js` to the root of your GitHub Pages repository.

The frontend includes the SmartSlot dashboard, wallet, Telebirr deposit/withdraw forms, history and profile screens.

Important: GitHub Pages is static. `API_BASE` in `app.js` is empty until you connect a secure backend. Do not put a Telegram bot token, database password, payment secret, or admin credentials in this repository.
